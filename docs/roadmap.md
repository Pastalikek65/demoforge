# Roadmap and release gates

## MVP candidate

Capture → edit/save → replay → real MP4/GIF and screenshot guides. Synthetic shop example. Fresh Windows integration and independent findings closure before public MVP publication.

## Beta

Annotations/subtitles, temporal zoom and cursor emphasis, supplied audio timeline, complete cancellation, safe review previews, adversarial input tests, accessibility, package/dependency inventory and representative performance measurements.

## v1.0.0 gate

Clean Windows/Linux x64 package installs and real end-to-end capture/replay/export checks. Version compatibility, changed-target failure, output decoding, time-based masking, secret non-persistence, data preservation and interrupted cleanup verified. No open critical/high findings. Independent review closure, release artifacts and SHA-256, support matrix and unsigned-package disclosure.

## Later

Multi-tab flows, richer selectors/authentication helpers, signed installers and additional platforms. These are not promised in v1.
