# Roadmap and release gates

## Delivered in 1.0.0

- MVP: single-tab capture, editable steps, local save/open, real replay and MP4/GIF/Markdown/HTML outputs; public source and a synthetic shop example.
- Beta: temporal opaque masks, trim/crop, annotations/subtitles, zoom/cursor emphasis, supplied audio, runtime variables, cancellation and malformed-input checks; accessible controls and a scoped performance measurement.
- Stable qualification: fresh Windows x64 and Ubuntu 24.04 x64 archives tested for installation, browser setup, recording/replay, masking/captions, four-format output checks and reopening. Versioned-format source checks, independent review, dependency/license inventory, SHA-256 and unsigned-package disclosure accompany the release.

The [verification record](verification.md) distinguishes source, manual and package evidence. No independent user pilot, universal website compatibility or additional platform support is claimed.

## Future work

Multi-tab flows, richer selectors and authentication helpers, signed installers, additional platforms, and a graphical mask editor are future work. They are not included or promised in 1.0.0.

## Maintenance

Keep reports reproducible with synthetic examples. Preserve versioned-format rejection, secret exclusion, output integrity, cancellation and sandbox boundaries in future changes. Qualify new distribution artifacts on supported platforms before publishing them.
