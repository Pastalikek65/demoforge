# Development ledger

Stage: preparation. No public repository or release yet.

## Ownership

- Root: shared contracts/config, Electron/IPC, CLI, integration and release.
- Core agent: src/core/project.ts and tests/core only.
- Browser agent: src/browser and tests/browser only.
- Editor agent: src/renderer and tests/editor only.
- Media processing and independent reviewers will follow after integration; never infer acceptance from an author report.

## Required before MVP

Real browser capture/replay, project edit/save/reopen, MP4/GIF/HTML/Markdown opened and validated, clear failure results. No fake recording or screenshot slideshow.

All approved editing/privacy/runtime-variable/headless features, tested Windows/Linux installed packages, secret-safe export review, interruption and hostile-input tests, compatibility tests, measurements, fresh independent findings closure, notices, release artifacts/checksums and genuine demo. Raw recordings may contain secrets; never describe them as sanitized.
