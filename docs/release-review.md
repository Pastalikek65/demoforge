Review date: 2026-10-08  
Reviewed baseline: `ba71d08` plus the package-smoke caption-crop correction. Current local audio-editor changes and the CI-only Linux namespace observer are under a separate independent v1 gate audit.
Scope: masking and export filters, secret URL and form variables, run/workflow binding, project and run compatibility, cancellation, Electron IPC and preview boundaries, browser setup, package CI, and license notices. Review fixtures use synthetic data and local services only.

## Source findings

No functional or privilege-boundary source finding remains open in the reviewed baseline and subsequent audio/observer changes. A separate GPT-6 Luna `xhigh` read-only review covered the latter changes; visual-marker coverage and platform package qualification remain separate acceptance work. The four earlier P2 findings are closed:

- **Run/workflow mismatch:** run reports now carry a SHA-256 fingerprint of replay behavior. `validateRun()` checks it as well as ordered step IDs; Electron and CLI export both reach that validation. Presentation edits do not invalidate a run, while replay behavior edits do. `tests/release-review/run-binding.test.ts` exercises changed targets and other behavior fields.
- **Secret URL persistence:** recognized sensitive query keys, OAuth `code`, and sensitive keys in fragment/query routes are detected. Recording stores those navigation URLs as secret runtime-variable references. Project parsing rejects a recognized sensitive literal URL with a constant message that asks the user to use a runtime variable, without echoing the value. Long URLs also use runtime variables. The recording regression uses synthetic `?access_token`, `?code`, and `#access_token` values and checks that neither the saved project nor run report contains them.
- **Cancellation during browser startup:** recording and replay attach abort handling before launch, race startup against cancellation, and close a browser that resolves after cancellation. The release-review cancellation tests cover a launch promise held pending until after the cancel request.
- **Timed masks with low-frame-rate input:** export normalizes video to 25 fps before applying timed masks, so duplicated output frames receive the correct mask state. The synthetic FFmpeg regression checks pixels at the mask boundary.

The review also found and closed a runtime-variable validation mismatch. The project parser, editor, and IPC boundary now share the reserved-name check for `constructor`, `prototype`, and `__proto__`; invalid names are rejected before persistence. A prior direct probe showed that the parser accepted these names while replay rejected them. After the shared check was added, the project, renderer, and boundary tests passed together.

The review also found that Playwright's default Chromium launch disables its OS sandbox. Both recording and replay now set `chromiumSandbox: true`, and a regression test checks both call sites. The installer now accepts an abort signal, requests process-tree cleanup on cancellation and timeout, and removes the signal listener on completion. Closing the last editor window aborts installation and waits for installer cleanup, the active operation, and browser service shutdown before quitting. Windows uses `taskkill /T /F` for the owned child PID and reports when cleanup cannot be verified. Linux starts a detached process group, sends `SIGTERM`, checks whether the group remains after the grace interval, and sends `SIGKILL` only if it does.

## Boundaries and compatibility

Electron IPC accepts calls only from the exact local editor URL in the main frame. The renderer remains sandboxed with context isolation and Node integration disabled; navigation, popups, webviews, permissions, and arbitrary preview paths are denied. Preview requests resolve only through the main-process URL-to-file map.

The browser setup bridge takes no caller-controlled program, URL, or flags. Main launches the locked Playwright CLI with fixed `install chromium` arguments, sets its download location under the app's per-user data directory, records installer output in `browser-runtime/install.log`, and applies a ten-minute timeout. The installer explicitly enables Node's system certificate store, preserves `NODE_EXTRA_CA_CERTS`, and removes arbitrary `NODE_OPTIONS`, TLS verification bypass, and Playwright alternate download-host overrides. The renderer can request this operation only through the trusted local-editor IPC handler.

Project schema version 1 remains supported with one documented pre-release exception: literal navigation URLs containing recognized sensitive query or fragment keys must be converted to declared runtime URL variables before opening. Pre-release run reports without the newly required workflow fingerprint must be replayed. These compatibility limits are documented in `docs/architecture.md`; no stable v1 format has been published. The detector remains heuristic, so users should review URLs and outputs before sharing.

The package configuration downloads Chromium during explicit first-run setup and does not bundle the browser or export FFmpeg. Package notices include the locked production dependency inventory and texts plus Electron runtime attribution; the external browser download and locally selected FFmpeg have separate terms. The Windows ZIP and Linux archive are unsigned. The inventory describes declared metadata and found notice files; it does not establish license compliance.

Mask geometry and timing are edited numerically. The canvas shows the raw capture with mask overlays, not a rendered export; the review checkbox requires an explicit review before export. This limits redaction-preview convenience but did not produce a separate source-level masking bypass in the reviewed export path.
