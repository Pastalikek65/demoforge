# Security

Raw videos, screenshots and imported audio can contain sensitive data. Runtime password detection is limited; review regenerated outputs before sharing. Keep capture directories private. No network upload backend or telemetry is provided.

For a security issue, use GitHub's private vulnerability reporting on this repository when enabled. If it is unavailable, contact the owner through a contact method listed on the GitHub profile; do not post exploit details or secrets in a public issue. Public issues are appropriate for ordinary bugs with synthetic reproductions.

Only published supported releases receive fixes. There is currently no stable supported release. This project is not a universal data-loss-prevention tool or a sandbox for hostile programs.
